## 2026-11-25 — Single-threaded BLAS for R baselines

- **Fix**: MICE with environmental and phylogenetic columns was very slow. An R profile of one fold-0 fit (151 species × 118 columns, 34 incomplete; `m = 1`, `maxit = 1`) spent 97.5% of its time in `eigen()`, called by `mice::remove.lindep` for every variable and iteration. Multithreaded OpenBLAS oversubscribed the shared 36-core machine: 3,441 s CPU for 250 s wall. With `OPENBLAS_NUM_THREADS=1` the same fit took 6.8 s, with the MICE specification unchanged. `r_baselines_fit.py` now sets this default before numpy and R load (`os.environ.setdefault`, so an exported value wins). Bypassing `remove.lindep` (`eps = 0`, 5.5 s) was not adopted because it changes the imputation model. README and [benchmark protocol](experiments/benchmark-protocol.md) updated.
- **Validation**: Real-data seed-42/fold-0 baseline smoke run (`--use_env_features true --use_phylo_features true`, MICE at default `m = 5`, `maxit = 5`; RF and MLP with one search candidate and two inner folds) completed in 327 s: MICE, RF and MLP each exported 448 evaluated cells, all finite and nonnegative, and RF/MLP wrote `prediction_safeguards.csv`. Functional checks only.
- **Open — MICE baseline defects (pre-existing, not fixed).** In that smoke run MICE reversed 123 of 224 evaluated (min, max) pairs (RF 0, MLP 1) and predicted far below the observed ranges, for example Ferstipe max RMSE 528 against RF 254. Rerunning with first-completion scoring gave the same pattern, so the pooling change did not cause it. Three causes were identified on fold 0:
  1. A few extreme training spore values (`SporeMax` up to 168,483 and `SporeMin` up to 89,704, against medians of 1,139 and 465) make `SporeMin`/`SporeMax` correlate at 0.9996. `mice`'s collinearity screen then drops `SporeMax` (method `""`): it is never imputed, test rows come back ≈ 0, and the midpoint projection averages them with `SporeMin`. This belongs with TODO R5.2 (units/outliers).
  2. `remove.lindep` removes about 30 predictors per variable per iteration (783 logged events), often the most informative traits.
  3. Test-time `mice.mids(newdata=..., maxit = 1)` runs one pass in which each target's masked paired partner still holds its initial value.

  On fold 0, disabling both screens (`remove.collinear = FALSE`, `eps = 0`) and using `maxit = 5` at test time cut reversals to 4/224 and brought stipe and frond errors close to RF (Ferstipe max 348, min 27.0). Spore max stayed dominated by the outlier donors. This is a candidate fix awaiting a decision, not implemented; one fold, one seed.

## 2026-11-25 — Shared prediction safeguards and pooled MICE

- **Fix**: The GNN inverse transform could return infinity: the Yeo–Johnson inverse is undefined beyond 1/|λ| for λ < 0 (altitude and spore minima on the full cohort), and `NormalizeFeatures.inverse` only clipped its base at zero. The GNN also passed original-scale outputs through softplus, which inflates small positive values (softplus(1) ≈ 1.31), while the ML baselines used bounded extrapolation and a hard zero clip. Both now use `prediction_bounds.bounded_inverse`: clip to the fitted observed transformed range ± 1 SD, invert, fall back to the observed range if still non-finite, and set negative values to zero for target columns whose fitted values were all nonnegative. The GNN range is fitted with its normalization on outer-training cells, excluding the inner-validation cells; recorded targets are never clipped. `inverse(soft_clip=...)` became `inverse(bounded=...)`; `inverse_tensor` (order penalty) clamps to the same window. See [training and masking](methodology/training-and-masking.md#transformations) and [ML baselines](updates/ml-baselines.md).
- **Fix**: Non-finite predictions now fail at the fold that produces them: `tester.long_predictions_frame` raises `AnalysisConsistencyError` for non-finite evaluated cells (GNN and baselines); `r_baselines_fit.evaluate_and_save` no longer silently drops them, and raises unless the model is tree-dependent and the value is missing; `run_benchmark.check_original_scale` also checks the merged long export. See [analysis conventions](experiments/analysis-conventions.md).
- **Fix**: MICE was scored on the first of its `m = 5` completed datasets, i.e. one random draw. Both protocols now score the mean across completions (`r_models.pool_completions`). See [benchmark protocol](experiments/benchmark-protocol.md).
- **Validation**: 50 tests passed in the README R/Python environment, including new `tests/test_prediction_bounds.py` (λ < 0 overflow stays finite, in-range values unchanged, signed traits not clipped, masked cells excluded from the range, identical GNN/ML output for identical transformed predictions, MICE pooling, per-fold rejection). Real-data seed-42/fold-0 smoke runs: a 2-epoch GNN (CPU) exported 448 evaluated cells, all finite and nonnegative, with no reversed pairs; the baseline smoke run is recorded in the "Single-threaded BLAS for R baselines" entry above. Functional checks only.
- **Decision**: Results produced before this entry keep their original postprocessing (unbounded inverse + softplus for the GNN, first-imputation MICE) and are not relabelled. The manuscript statements remain accurate and were not changed.

## 2026-11-24

- **Decision**: Predicted bounds are ordered by a post-hoc midpoint projection on the original scale, applied to test outputs and conformal calibration (`--enforce_bounds_order`, default on). On 5 matched seeds it guaranteed min ≤ max with no measurable change in accuracy (49/5,670 pairs projected, all stipe traits). Min-plus-range ReLU/Softplus heads lost accuracy and overflowed on `Alt max`, and a soft order penalty (`--order_penalty_weight`, default 0) had no effect. Details: [ordering of predicted bounds](methodology/bounds-parameterization.md). Manuscript Methods, hyperparameter table and Results paragraph were revised, and the reviewer response now includes a note on the rejected alternatives.

- **Fix**: Normalization is now fitted after the internal validation cells are selected and excluding them, so checkpoint selection no longer shares preprocessing statistics with its own targets (`train.py`; regression test `tests/test_internal_validation_independence.py` now passes). A guard stops training if a trait keeps fewer than 10 fit observations; the observed minimum over 3 seeds × 5 folds was 116 (`Spore`).
